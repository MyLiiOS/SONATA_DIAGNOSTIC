# SONATA DIAGNOSTIC

Персональная автомобильная диагностическая система.

Автомобиль:
Hyundai Sonata TagAZ EF IV 2008
Двигатель: 2.0
Коробка: механическая

Разработка:
Kotlin
Jetpack Compose
Android
Bluetooth Classic
OBD-II / ELM327
SQLite / Room

Минимальная Android: 11 (API 30)
Целевая Android: 16 (API 36)

Основные задачи:
- Мониторинг двигателя
- Чтение ошибок ЭБУ
- Регистрация параметров
- Диагностика запуска
- Анализ неисправностей
- История измерений
- Экспорт CSV
